# AI-Voice-Studio-
AI Voice Studio is a next-generation voice AI platform designed to give creators, businesses, and developers complete control over audio. Built as a powerful ElevenLabs alternative with a sharp focus on South Asian languages, it delivers studio-grade speech at half the cost.

# 🎙️ AI Voice Studio

A multi-feature AI voice tool built with Streamlit.

## Features
- Text to Speech (multi-language)
- Speech to Text
- File to Speech (PDF, DOCX, TXT)
